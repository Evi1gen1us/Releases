Notea

Notea is a notes app for Android: text notes, checklists, shopping lists, drawings, voice notes and mind maps. Notes are stored on the phone.

Optionally, your devices can keep the same notes (end-to-end encrypted), and Notea can save automatic backups of your notes to your own Google Drive. It uses only the drive.file permission, so it sees only the backup files it created itself, in a folder named “Notea”.
